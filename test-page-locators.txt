PRACTICE LAB PLAYWRIGHT LOCATORS
================================

The examples below target elements from index.html > Practice lab.

1. ROLE LOCATORS
----------------

// Username textbox
await page.getByRole('textbox', { name: 'Username' }).fill('tester');

// Submit button
await page.getByRole('button', { name: 'Submit' }).click();

// Accept the confirmation dialog
page.once('dialog', dialog => dialog.accept());
await page.getByRole('button', { name: 'Alert button' }).click();

// Reject the confirmation dialog
page.once('dialog', dialog => dialog.dismiss());
await page.getByTestId('alert-button').click();

// Disabled button
await page.getByRole('button', { name: 'Disabled' }).isDisabled();

// Table
await page.getByRole('table').isVisible();

// Table row
await page.getByRole('row', { name: /Apple.*\$1.*Available/ }).isVisible();

// Link
await page.getByRole('link', { name: 'External link' }).click();

13. PLAYWRIGHT ACTION PRACTICE
------------------------------

// Mouse actions: hover()
await page.getByTestId('action-hover-target').hover();

// Keyboard actions: press()
await page.getByTestId('keyboard-input').press('Control+A');
await page.getByTestId('keyboard-input').press('Enter');

// Text selection: selectText()
await page.getByTestId('select-text-input').selectText();

// Scrolling: scrollIntoViewIfNeeded()
await page.getByTestId('scroll-target').scrollIntoViewIfNeeded();

// File upload: setInputFiles()
await page.getByTestId('file-input').setInputFiles('sample.txt');

// Checkbox actions: isChecked(), uncheck()
await page.getByTestId('newsletter-checkbox').isChecked();
await page.getByTestId('newsletter-checkbox').uncheck();

// Element state methods
await page.getByTestId('sample-image').isVisible();
await page.getByTestId('hidden-button').isHidden();
await page.getByTestId('submit-button').isEnabled();
await page.getByTestId('disabled-button').isDisabled();
await page.getByTestId('editable-state').isEditable();

// Multiple elements: first(), last(), nth()
await page.getByTestId('multiple-action').first().click();
await page.getByTestId('multiple-action').last().click();
await page.getByTestId('multiple-action').nth(1).click();

// Frames: frameLocator()
await page.frameLocator('[data-testid="practice-frame"]').locator('body').isVisible();

// Content retrieval: textContent()
const text = await page.getByTestId('content-retrieval-target').textContent();

12. LOCATOR PRIORITY
--------------------

1. Prefer getByRole() for accessible user-facing controls.
2. Use getByLabel() for form fields.
3. Use getByTestId() for stable automation contracts.
4. Use getByText() for visible text when appropriate.
5. Use CSS selectors for implementation-specific cases.
6. Avoid XPath unless no better locator is available.

Example chain:
const form = page.getByTestId('test-form');
await form.getByLabel('Username').fill('tester');
await form.getByLabel('Password').fill('secret');
await form.getByRole('button', { name: 'Submit' }).click();
