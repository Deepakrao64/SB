Pull vs fetch

Same download, different result

git fetch downloads remote commits but leaves your working files unchanged. git pull fetches and then merges those commits into your current branch.

Safe context switch

git stash

Temporarily saves uncommitted work so you can switch branches. Return later and use git stash pop to restore it.

When work collides

Conflicts & rebase

A conflict happens when Git cannot choose between overlapping changes. Resolve the intended code, then continue. git rebase replays your commits on top of another branch's latest commits.

Git is the version-control software that tracks file history. GitHub, GitLab, and Bitbucket are web platforms that host Git repositories.
